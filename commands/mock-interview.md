# /mock-interview

## 목적
사용자의 프로젝트 기반 기술 면접 시뮬레이션을 수행합니다.
꼬리질문으로 기술적 깊이를 테스트하고, 취약점을 발견합니다.

## 에이전트 역할
config/agent-roles.md → Interview Coach

## 입력
- src/user-profile.md
- src/projects/*.md (질문 소스)
- config/interview-depth-model.md (L1~L5 모델)
- 사용자 선택: 특정 프로젝트 / 특정 기술 주제 / 랜덤

## 실행 절차
1. 면접 모드 선택 (사용자에게 물어봄):
   - 프로젝트 기반: 특정 프로젝트 심층 질문
   - 기술 주제 기반: CS 기초, 시스템 설계, DB 등
   - 종합: 프로젝트 + 기술 + 인성 혼합

2. 질문 → 답변 → 평가 → 꼬리질문 루프:

   **[질문 규칙]**
   - 한 번에 하나의 질문만
   - 사용자 답변을 기다린 후 평가
   - 정답을 먼저 알려주지 않음
   - 답변 수준에 따라 깊이 동적 조절:
     - 잘 답변 → 다음 레벨로
     - 막히면 → 힌트 1개 제공 후 재질문
     - 힌트 후에도 막히면 → 모범 답안 제시 후 다음 질문

3. 세션 종료 후:
   - 전체 평가 요약 (항목별 레벨)
   - 취약 주제 목록
   - 학습 과제 생성

## 출력
- outcome/interview/mock_{topic}_v{N}_{YYYYMMDD_HHmmss}.md
  - 질문, 사용자 답변(요약), 평가, 모범 답안, 개선점
- outcome/learning/{topic}.md (취약 주제 학습 가이드, 필요시)

## 규칙
- 한 세션 5~10개 질문 (사용자 조절 가능)
- 모범 답안은 사용자의 실제 프로젝트 맥락으로 작성
  (일반론이 아닌 "당신의 프로젝트에서는 이렇게 답변할 수 있습니다")
- 평가는 솔직하게 (과도한 칭찬 금지)

## 제안 트리거
- L2 이하에서 자주 막히는 주제가 있으면:
  → "이 주제는 심화 학습이 필요합니다. outcome/learning/ 에 학습 가이드를 생성했습니다"
- 프로젝트 설명이 부족해서 질문 생성이 어려우면:
  → "/intake-project 로 프로젝트 상세를 보강하면 더 실전적인 질문이 가능합니다"
- 특정 프로젝트에서 L4~L5 통과:
  → "이 프로젝트는 시니어급 답변이 가능합니다. 이력서에서도 이 깊이를 반영하세요"
