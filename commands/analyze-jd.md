# /analyze-jd

## 목적
채용공고를 분석하고 사용자 프로필과의 매칭률을 산출합니다.

## 에이전트 역할
config/agent-roles.md → Market Analyst + Career Advisor

## 입력
- src/jd/{file}.md (분석 대상 JD)
- src/user-profile.md
- src/projects/*.md

## 실행 절차
1. JD 파싱:
   - 필수 요구사항 / 우대사항 분리
   - 기술 스택 추출
   - 역할/책임 추출
   - 숨겨진 요구사항 추론

2. 매칭 분석:
   - 각 요구사항별 매칭 (✅ 충족 / ⚠️ 부분 충족 / ❌ 미충족)
   - 전체 매칭률
   - 강점 (차별화 포인트)
   - 갭 (부족한 부분 + 보완 방법 + 예상 소요 시간)

3. 맞춤 전략:
   - 이력서에서 강조할 프로젝트 순서
   - 면접 예상 질문
   - 준비해야 할 기술 주제

4. 지원 추천: ✅ 추천 / ⚠️ 조건부 / ❌ 비추천 + 이유

## 출력
- outcome/analysis/jd_{company}_{position}_v{N}_{YYYYMMDD_HHmmss}.md

## 규칙
- 매칭률 보수적 평가 (과대 산정 금지)
- 갭 분석에서 "단기 보완 가능" vs "장기 학습 필요" 구분
- 검증 가능한 정보만 사용 (추측은 [미확인] 태그)

## 제안 트리거
- 매칭률이 높으면:
  → "/draft-resume 로 이 JD에 맞춤화된 이력서를 만들어보세요"
- 특정 기술 갭이 있으면:
  → "/mock-interview 로 해당 기술 주제를 연습하세요"
