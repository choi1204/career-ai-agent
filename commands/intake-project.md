# /intake-project

## 목적
새 프로젝트/업무 경험을 체계적으로 기록하고, 이력서 반영 여부를 판단합니다.

## 에이전트 역할
config/agent-roles.md → Career Advisor

## 입력
- 사용자의 자연어 설명 (대화형)
- src/user-profile.md (기존 경력과 비교)
- src/projects/ (기존 프로젝트와 중복 체크)
- templates/project-template.md (구조 참고)

## 실행 절차
1. 사용자에게 구조화된 질문 (STAR + 기술 심화):

   **[기본 정보]**
   - 프로젝트명, 기간, 소속 팀

   **[Situation]**
   - 어떤 배경/문제가 있었는가?
   - 비즈니스 맥락은?

   **[Task]**
   - 본인의 역할과 책임은?
   - 팀 규모와 본인 기여 범위는?

   **[Action - 기술 심화]**
   - 어떤 기술적 선택을 했는가?
   - 왜 그 기술/패턴을 선택했는가? (대안 비교)
   - 기술적 도전과 해결 과정은?

   **[Result]**
   - 정량적 결과는? (수치 + 측정 방법)
   - 정성적 결과는?
   - 수치의 출처는? (대시보드, 보고서 등)

2. 이력서 반영 판단:
   - 기존 프로젝트와 차별성
   - 타깃 포지션과 관련성 (src/jd/ 참고)
   - 임팩트 크기
   → ✅ 추가 추천 / ⚠️ 조건부 / ❌ 불필요 + 이유

3. 프로젝트 파일 생성

## 출력
- src/projects/{project-name}.md
- 콘솔에 이력서 반영 판단 결과

## 규칙
- 답변하지 않은 항목은 [미입력]으로 표시 (임의로 채우지 않음)
- 수치는 출처와 함께 기록 요청
- 기존 프로젝트와 겹치면 병합 제안

## 제안 트리거
- 프로젝트의 기술적 깊이가 풍부하면:
  → "이 프로젝트는 면접 질문 소스로도 좋습니다. /mock-interview 로 연습해보세요"
- evidence/ 에 추가할 자료가 있으면:
  → "대시보드 캡처를 src/evidence/{project-name}/ 에 추가하면 팩트체크에 활용됩니다"
