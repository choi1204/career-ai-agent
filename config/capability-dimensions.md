# 역량 평가 차원

## 평가 척도
| 점수 | 의미 | 설명 |
|------|------|------|
| 1 | 미경험 | 해당 영역 경험/지식 없음 |
| 2 | 기초 | 기본 개념 이해, 가이드 하에 수행 가능 |
| 3 | 중급 | 독립적 수행 가능, 일반적 문제 해결 |
| 4 | 고급 | 복잡한 문제 해결, 트레이드오프 판단, 멘토링 가능 |
| 5 | 전문가 | 아키텍처 설계, 기술 리딩, 조직 영향력 |

## 차원 1: 기술 역량 (Technical Skills)
### 평가 기준
- 주력 기술 스택의 깊이
- 기술 선택의 근거와 트레이드오프 이해
- 새 기술 습득 속도와 적용 능력

### 데이터 소스
- src/projects/*.md → 사용 기술, 기술적 도전
- outcome/interview/*.md → 기술 질문 L레벨
- src/user-profile.md → 기술 스택

### 세부 항목
- 프로그래밍 언어 숙련도
- 프레임워크/라이브러리 활용
- DevOps/인프라 이해
- 테스트/품질 관리

- 알고리즘적 사고

### 데이터 소스

- 알고리즘/자료구조
- 디버깅 능력
- 창의적 해결
