# 면접 질문 깊이 모델

## L1: What (무엇을 했나?)
- "이 프로젝트에서 본인의 역할은?"
- "어떤 기술을 사용했나요?"
- **통과 기준**: 프로젝트를 설명할 수 있음

## L2: Why (왜 그렇게 했나?)
- "왜 이 기술/패턴을 선택했나요?"
- "어떤 문제를 해결하려 했나요?"
- **통과 기준**: 의사결정 근거를 설명할 수 있음

## L3: Alternative (대안은?)
- "다른 방법은 고려했나요?"
- "A 대신 B를 썼다면?"
- **통과 기준**: 대안을 비교할 수 있음

## L4: Tradeoff (트레이드오프는?)
- "이 선택의 단점은?"
- "성능 vs 일관성 사이 판단은?"
- **통과 기준**: 엔지니어링 트레이드오프를 이해함

## L5: Retrospective (회고)
- "다시 한다면 어떻게?"
- "규모가 10배면?"
- **통과 기준**: 성장 가능성, 시니어 사고방식

## 동적 난이도 조절
```
L1 시작
  │
  ├─ 잘 답변 → L2
  │              ├─ 잘 답변 → L3
  │              │              ├─ 잘 답변 → L4
  │              │              │              ├─ 잘 답변 → L5
  │              │              │              └─ 막힘 → 힌트 → L4 재질문
  │              │              └─ 막힘 → 힌트 → L3 재질문
  │              └─ 막힘 → 힌트 → L2 재질문
  └─ 막힘 → 힌트 → L1 재질문

  힌트 후에도 막힘 → 모범 답안 제시 → 다음 질문으로 이동
```
