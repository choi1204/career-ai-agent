# 브랜드 거래액 54.3% 상승을 이끈 보장형 배너 시스템 구축

## 기본 정보
- **기간**: 2024.04 ~ 2024.05
- **소속**: 무신사(29CM) 전시 콘텐츠팀
- **역할**: 전시 시스템 백엔드 개발자
- **팀 규모**: [UNVERIFIED: 확인 필요]
- **본인 기여 범위**: 슬롯 기반 배너 노출 구조 설계, Redis FIFO 롤링 구조 설계/구현

## Situation (배경)
기존 배너 시스템은 노출 위치를 등록자가 수동으로 계산해야 했고, 노출 보장이 어려워 실제 집행된 배너 중 약 76%가 약속된 위치에 노출되지 않는 이슈. 브랜드와의 신뢰 저하, 거래 실적 손실 등 비즈니스 리스크 발생. 정량 보장형 판매 상품 확대에 제약.

## Task (과제)
노출 위치 보장형 배너 시스템을 설계하여 브랜드 신뢰 확보 및 거래 실적 향상.

## Action (행동)
### 기술적 선택
- **사용 기술**: Redis (List 기반 FIFO), 슬롯 기반 구조
- **선택 이유**: 단순성과 예측 가능성 확보. "등록한 순서대로, 지정된 시간대에 반드시 노출됨"
- **고려한 대안**:
  - LexoRank 기반 정렬: 정렬 기준 갱신 부담과 복잡도가 높아 제외
  - 개인화 추천 전략: 세일즈팀의 예측 가능한 노출 시간 보장이 우선시되어 제외
- **트레이드오프**: FIFO 단순 구조로 성과 기반 최적화는 포기, 예측 가능성/운영 편의성 확보

### 구현 상세
- 슬롯 기반 배너 노출 구조 설계로 운영 자동화 달성
  - 운영자가 노출 위치와 시간대를 선언적으로 등록 → 시스템이 슬롯 자동 배정
  - 등록부터 노출까지 완전 자동화
- Redis 기반 FIFO 롤링 구조 설계
  - 각 슬롯당 복수 배너 등록 허용, Redis 리스트로 순차적 롤링 노출

### 기술적 도전
- 노출 간섭 없는 슬롯 자동 배정 로직 설계
- 다수 배너의 순차 롤링과 시간대별 정확한 노출 보장
