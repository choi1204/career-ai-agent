## Situation (배경)
기획전 참여 쿠폰/브랜드 정보를 매번 스프레드시트로 수작업 입력하면서 데이터 반영 지연과 휴먼 에러가 빈번. 변경 사항 반영에 평균 1시간 이상 소요. 연간 수만 건의 반복 업무가 누적. 프로모션 적시성 저하로 이어지는 운영 리스크 존재.

## Task (과제)
기획전 참여 쿠폰/브랜드 정보의 실시간 정합성 검증 자동화, 운영 어드민 구축으로 수작업 제거.

## Action (행동)
### 기술적 선택
- **사용 기술**: 병렬 처리, 청크 처리, 어드민 시스템
- **선택 이유**: 2000건 이상 쿠폰 검증 시 병목 해소를 위한 구조적 접근
- **고려한 대안**: 쿠폰 도메인에 단일 브랜드 전용 타입 및 브랜드 조회 API 추가
- **트레이드오프**: 기획전 운영 어드민 설계/개발로 프로모션 통합 관리 체계 토대 마련

### 구현 상세
- 참여 쿠폰 validation 시스템 설계 및 구현으로 실시간 정합성 검증 자동화
- 쿠폰 → 상품 → 브랜드 경로로 브랜드 정보 역추적 로직
- 병렬 처리 + 청크 처리로 2000건 이상 쿠폰 검증 병목 해소
- 어드민 등록 시점에 브랜드 쿠폰이 적용 가능한 브랜드 정보를 자동 enrich
- 1시간 단위 배치 → 어드민에서 동기적 실시간 반영으로 전환

### 기술적 도전
- 쿠폰 → 상품 → 브랜드 역추적 경로에서 2000건 이상 처리 시 병목 해소
