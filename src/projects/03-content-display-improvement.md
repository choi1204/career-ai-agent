# 재방문율 2.3배 향상을 이끈 콘텐츠 전시 구조 개선

## 기본 정보
- **기간**: 2025.01 ~ 2025.03
- **소속**: 무신사(29CM) 전시 콘텐츠팀
- **역할**: 전시 시스템 백엔드 개발자
- **팀 규모**: [UNVERIFIED: 확인 필요]
- **본인 기여 범위**: 묶음 단위 콘텐츠 구성/통합 조회, 이미지 자동 가공, Kotlin 전환

## Situation (배경)
기존 홈메인 구조는 카테고리 중심으로 구성되어 뷰티/홈/테크 등 낯선 카테고리로의 자연스러운 진입이 어려움. 크로스 카테고리 탐색 제한, 상품 중심의 획일적 경험만 제공. 브랜드 아이덴티티 흐려짐, 지면별 컨텍스트 분산으로 일관된 UX 설계 어려움. 전사적 '발견' 페이지 프로젝트가 기획됐으나 콘텐츠를 유연하게 그룹화하고 일관된 구조로 제공하는 기반 부족.

## Task (과제)
콘텐츠를 묶음 단위로 구성하고 통합 조회할 수 있는 구조 설계, 비표준 이미지 자동 가공, 레거시 Kotlin 전환.

## Action (행동)
### 기술적 선택
- **사용 기술**: Kotlin, Spring Boot, 배치 처리
- **선택 이유**: 레거시 자바 코드 Kotlin 전환으로 유지보수성 개선, 팀 컨벤션 통일
- **고려한 대안**: ElasticSearch 기반 콘텐츠 검색 (일정상 미구현)
- **트레이드오프**: 전환 비용 vs 장기 유지보수성/일관성 확보

### 구현 상세
- 묶음 단위 콘텐츠 구성 및 통합 조회 기능 설계
  - 분산된 콘텐츠를 통합 조회, 실험군 기반 유저별 콘텐츠 노출 동적 제어 기반 마련
- 비표준 콘텐츠 대응을 위한 이미지 자동 가공 시스템 구축
  - 콘텐츠별 전시 타입에 따른 이미지 자동 인플레이팅 (1종 → 4종)
  - 가로/레이아웃이 다른 콘텐츠를 자동 변환하는 배치 기반 처리 구조 설계
- 콘텐츠 도메인의 Kotlin 전환 및 구조 정비

### 기술적 도전
- 다양한 콘텐츠 유형별 이미지를 자동 변환하는 배치 처리 구조 설계
- 실험군 기반 유저별 콘텐츠 노출 동적 제어
