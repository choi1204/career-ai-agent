## Situation (배경)
기존 블랙프라이데이 이벤트는 할인 위주의 단방향 콘텐츠로 구성. 혜택에 관심 없는 유저는 참여하지 않고 이탈률이 높음. 특정 혜택에 집중된 구조는 전체 유저 대상 바이럴 확산에 한계. 참여 유도 → 공유 → 재유입의 선순환 구조가 필요.

## Task (과제)
유저가 직접 상품을 선택해 셀렉션을 만들고 공유할 수 있는 커뮤니티 구조를 설계하여 바이럴 확산과 재유입을 유도.

## Action (행동)
### 기술적 선택
- **사용 기술**: Redis 캐시, 비동기 처리, Seed 기반 랜덤 알고리즘, OG 이미지 동적 관리
- **선택 이유**: 고트래픽 이벤트 환경에서 lightweight하고 확산 가능한 구조
- **고려한 대안**: Redis 유저 응답 캐시 방식 → 불필요한 캐시 메모리 사용/갱신 비용으로 제외
- **트레이드오프**: Seed 기반 단순 구조로 개인화 포기, 메모리 효율/성능 확보

### 구현 상세
- 상품 기반 셀렉션 생성 및 공유 기능 설계
  - 사용자가 여러 상품을 선택해 자신만의 셀렉션 생성/외부 공유
  - 상품 변경 시 OG 이미지 자동 갱신되는 동적 이미지 관리 구조
- UV 기반 인기 셀렉션 정렬 기능 개발
  - 단순 PV가 아닌 고유 방문자(UV) 기준 인기 순위 산정
- Seed 기반 랜덤 노출 알고리즘 구현
  - 시간 단위 seed 값으로 랜덤 순서 노출
  - 별도 스토리지 없이 메모리 소비 없는 순환 구조 달성
- 트래픽 대응을 위한 캐시 및 비동기 처리 구조 적용
  - Redis 캐시 + 비동기 처리로 공유 이벤트 집중 시 병목 방지
  - OG 이미지 렌더링/등록 처리 로직 비동기화

### 기술적 도전
- 고트래픽 이벤트에서 메모리 효율적인 랜덤 노출 구조 설계
- OG 이미지 동적 생성/갱신의 비동기 처리
