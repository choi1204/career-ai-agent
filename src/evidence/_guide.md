# 증거 자료 등록 가이드

## 왜 증거가 필요한가?
이력서에 "거래액 54% 증가"라고 쓰려면, 그 수치의 출처가 있어야 합니다.
출처가 없으면 면접에서 "이 수치는 어떻게 측정했나요?"에 답할 수 없고,
시스템도 해당 수치를 [UNVERIFIED]로 처리합니다.

## 등록 가능한 증거 유형
1. **대시보드 스크린샷** (.png, .jpg)
2. **내부 보고서/문서 링크** (접근 불가 시 요약 텍스트)
3. **PR/커밋 링크**
4. **성과 리뷰 문서**
5. **Jira/Confluence 링크**

## 파일 구조
```
evidence/
├── {project-name}/
│   ├── dashboard-gv-increase-2025-06.png
│   ├── pr-links.md
│   └── internal-report-summary.md
└── _guide.md (이 파일)
```

## 파일명 규칙
- `{내용}-{날짜}.{확장자}`
- 예: `discovery-tab-revisit-rate-20250615.png`

## 증거 파일에 포함할 내용 (텍스트인 경우)
```markdown
## 출처 정보
- 출처: (대시보드 URL, 문서 제목 등)
- 접근 가능 여부: (내부만 / 외부 공개)
- 캡처 일자:
- 관련 수치:
  - {지표명}: {수치} ({측정 기간})
```
